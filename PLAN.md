# JukeboxRadio — план работы

Плагин для Paper 26.3: радио в проигрывателе (jukebox). Shift + ПКМ по проигрывателю открывает меню
(GameUI), звук идёт через Simple Voice Chat позиционно от блока. Источники: ссылки Spotify
(трек / альбом / плейлист), YouTube (видео / плейлист), поиск по Spotify.

Статусы: `[ ]` — не начато, `[~]` — в работе, `[x]` — готово, `[!]` — есть риск/ограничение.

## 1. Архитектура (универсальная платформа)
```
su.nuv.radio
├── RadioPlugin                 — точка входа, сборка сервисов
├── config/                     — RadioConfig (config.yml), Messages (ru)
├── catalog/                    — УНИВЕРСАЛЬНЫЙ слой метаданных
│   ├── model/                  — TrackMeta, TrackCollection, SearchPage, ResolveResult
│   ├── MusicCatalog            — интерфейс провайдера (search / resolve / enrich)
│   ├── CatalogRegistry         — маршрутизация ссылок и выбор провайдера поиска
│   ├── spotify/                — SpotifyCatalog (Web API + embed/oEmbed фолбэки)
│   └── youtube/                — YouTubeCatalog (через lavaplayer)
├── audio/                      — AudioResolver (метаданные → поток), LavaplayerEngine,
│                                 PcmFrames (48k stereo → mono 960)
├── voice/                      — интеграция Simple Voice Chat (канал у блока, категория громкости)
├── station/                    — RadioStation (очередь, состояние, громкость), StationManager
├── ui/                         — GameUI: RadioScreen, UiNode-модель, RadioLayout, GameUiBridge,
│                                 CoverArt (обложка → пиксели), Sprites (генерация PNG), Preview
└── listener/                   — Shift+ПКМ по проигрывателю, ломание блока, выход игрока
```
Замена Spotify на другой сервис = новый класс `MusicCatalog` + строка в `config.yml`
(`catalog.search-provider`). Звук не зависит от провайдера: любой `TrackMeta` без прямого потока
ищется на YouTube Music по «исполнитель — название» с проверкой длительности.

## Риски и ограничения
- [x] ~~GameUI на 26.3~~ — не работает у клиента; интерфейс переписан на ванильные средства.
- [!] Spotify Dev Mode (с 09.03.2026): поиск ≤10 результатов за запрос; `/playlists/{id}/items`
      только для своих плейлистов; из треков убраны ISRC/popularity; нужен Premium у владельца
      приложения. Обход: треки чужих плейлистов/альбомов — через публичную embed-страницу,
      обложки — через oEmbed. Поэтому слой каталога сделан заменяемым.
- [!] Картинки в ресурс-пак попадают только при старте (новая текстура = перезагрузка пака), поэтому
      обложка рисуется «пикселями»: строки из спрайтов палитры 512 цветов с дизерингом.
- [!] YouTube ломает встроенный извлекатель youtube-source 1.18.2 (проверено: «must find sig
      function», SABR-форматы) — поэтому основной путь через yt-dlp. Поиск/метаданные lavaplayer
      работают.
- [!] Обновление заголовка «на месте» идёт через внутренний пакет сервера (рефлексия по Mojang-именам
      Paper). Если в будущей версии Paper имена поменяются, меню автоматически переоткрывается (курсор
      при этом прыгает в центр) — нужно будет поправить TitleUpdater.
